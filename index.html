Perangkat Keras (Hardware)

Hardware adalah komponen fisik komputer yang dapat disentuh, dilihat, dan dipindahkan. Dibagi menjadi 4 kategori utama:

1. Input Device (Perangkat Masukan)

Mengirim data dan perintah ke dalam komputer.

Contoh: Keyboard, Mouse, Scanner, Microphone, Touchscreen.

2. Process Device (Perangkat Pemroses)

Mengolah data yang dimasukkan input device.

Contoh: CPU (Otak Komputer), RAM (Memori Sementara), Motherboard.

3. Output Device (Perangkat Keluaran)

Menampilkan hasil pengolahan data kepada pengguna.

Contoh: Monitor, Printer, Speaker, Proyektor.

4. Storage Device (Perangkat Penyimpanan)

Menyimpan data secara permanen atau sementara.

Contoh: SSD, Harddisk (HDD), Flashdisk, Memory Card.

Perangkat Lunak (Software)

Software adalah program atau instruksi tak berwujud fisik yang menjalankan komputer.

Kategori 1

Sistem Operasi (Operating System)

Perangkat lunak dasar yang mengelola seluruh sumber daya hardware dan menghubungkan pengguna dengan komputer.

Windows Linux Android macOS
Kategori 2

Perangkat Lunak Aplikasi (Application)

Program khusus yang dirancang untuk menyelesaikan tugas spesifik pengguna (mengetik, menggambar, browsing).

Ms. Word / Excel Google Chrome Canva

Perangkat Manusia (Brainware)

Brainware adalah manusia yang mengoperasikan, mengatur, dan mengendalikan sistem komputer. Tanpa Brainware, komputer tidak bisa bekerja.

User / Operator

Pengguna biasa yang memakai aplikasi untuk kebutuhan sehari-hari.

Programmer

Orang yang menulis bahasa pemrograman untuk membuat software aplikasi.

Administrator

Penanggung jawab yang mengelola keamanan dan kelancaran jaringan/sistem.
